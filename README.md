# FIX-IT KARAOKE

Karaoke for PC, TV boxes and phones. Guests join from their phones, search songs,
add them to the queue and get a score after each song.

## Download

Get the latest version from **[Releases](https://github.com/felexsayri/fixit-karaoke/releases/latest)**:

| Device | File |
|---|---|
| Windows PC / laptop | `FIX-IT.KARAOKE.Setup.<version>.exe` |
| Android TV box | `FIX-IT.KARAOKE-TV-<version>.apk` |
| Android phone / tablet | `FIX-IT.KARAOKE-Mobile-<version>.apk` |

### Installing on Windows

Run the Setup file. If Windows shows "Windows protected your PC", click
**More info**, then **Run anyway**.

### Installing on Android

Copy the APK to the device (or download it there) and open it. Allow
"Install unknown apps" for your browser or file manager when Android asks.

## Songs are not included

The apps come without songs. Put your own songs in a folder named
`FIX-IT KARAOKE` (on the device, an SD card or a USB drive):

```
FIX-IT KARAOKE/
  karaoke/       karaoke videos (MP4, or MP4s inside ZIP files)
  midi/songs/    MIDI / KAR songs, or FIX-IT song packs (.fixidx + .fixblob)
  midi/sound/    SoundFonts (optional)
  midi/bgv/      background videos for MIDI songs (optional)
```

The app finds the folder by itself and numbers the songs.

### Background videos

The Android apps come without background videos, to keep them small. Download them
in the app: **Settings → Song library → Get songs & videos → From the internet**.

### Copy songs from your PC to a TV box or phone

If your FIX-IT PC already has a song pack, a TV box or phone on the same Wi-Fi
can copy it:

1. On the PC: **Settings → Share songs with a TV or phone**. A 6-digit code appears.
2. On the TV box or phone: choose **Get songs & videos → From my PC** (in setup,
   Settings, or the "No songs yet" message) and enter the code.

The songs keep the same numbers as on the PC.
